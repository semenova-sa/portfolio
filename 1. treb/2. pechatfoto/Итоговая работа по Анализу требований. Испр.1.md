## **Задача:** Разработать программное обеспечение для автомата, печатающего фото из Instagram или с телефона.

### **На встрече с представителем заказчика выяснили, что автомат должен работать следующим образом:**

1. При нажатии на кнопку «Выбрать фото для печати» на главном экране пользователю предложены 2 способа — выбрать фото в Instagram или загрузить фото с телефона.  
2. Для выбора фото из Instagram пользователю необходимо указать свой логин. Профиль пользователя должен быть открытым.  
3. Для выбора фото с телефона, пользователю нужно соединить телефон с автоматом для печати фото через кабель для зарядки.  
4. Пользователь может выбрать количество фотографий для печати через экран автомата. Минимальное количество фото — 1, максимальное —100 (если в автомате достаточно бумаги).  
5. Оплатить печать фото можно только по карте через физический терминал бесконтактной оплаты.  
6. Печать фото запускается после успешной оплаты выбранного пакета фотографий.  
7. Если пользователь вводил логин Instagram для печати фотографий, то после завершения печати его страница в автомате должна быть закрыта.  
8. Если пользователь присоединял телефон для печати фотографий, то после завершения печати автомат будет сигнализировать о необходимости забрать телефон.

### 3. **Текстовое описание варианта использования  "Распечатать фотографии"**

#### **3.1 Действующие лица:**

1. Основные  \- Пользователь  
2. Второстепенные \- Система автомата, Принтер, Терминал оплат  
   

#### **3.2  Предусловия:**

- Пользователь имеет действующую банковскую карту для оплаты  
- Если используется Instagram, профиль пользователя открыт, и у него есть доступ к интернету  
- Автомат включён и готов к работе  
- Достаточное количество бумаги для печати фотографий.


#### **3.3 Триггер**  
Нажатие на экране кнопки "Выбрать фото для печати"

#### **3.4  Основной поток событий**:

1. Пользователь нажал на кнопку «Выбрать фото для печати» на экране автомата  
2. Система предлагает пользователю: Выбрать фото в Instagram или загрузить с телефона  
3. Если пользователь выбрал загрузку из Instagram  
4. Система проверяет доступность аккаунта.   
5. Если аккаунт открыт, то управление переходит на следующий шаг  
6. Система предлагает пользователю выбрать фото для печати  
7. Пользователь выбирает фотографии  
8. Система предлагает пользователю ввести количество фото для печати  
9. Пользователь вводит количество фото  
10. Система проверяет количество бумаги  
11. Если в системе достаточно бумаги, то управление переходит на следующий шаг  
12. Система предлагает оплатить заказ  
13. Пользователь прикладывает карту к терминалу оплаты  
14. Если пользователь успешно оплатил заказ, то управление переходит на следующий шаг  
15. Терминал оповещает систему об успешной оплате  
16. Система отправляет фотографии на принтер  
17. Система завершает сессию, удаляет все данные пользователя и сигнализирует о завершении заказа  
18. Принтер печатает фотографии  
19. Вариант использования завершает свою работу  
      
#### **3.5 Альтернативные потоки:**  
      
**Альтернативный поток 3а**

   Если пользователь подключил телефон: 
1. Система проверяет подключение телефона  
2. Система выводит на экран найденные на устройстве фото  
3. Управление возвращается к шагу 4\.  
     
**Альтернативный поток 5а**  

   Если аккаунт закрыт, то:  
1. Система выводит сообщение: «Не удалось получить доступ к профилю. Проверьте настройки»  
2. Если пользователь хочет внести исправления, то управление возвращается на шаг 2  
3. Иначе переход в поток исключения 3б  
     
 **Альтернативный поток 11а** 
 
   Если бумаги недостаточно для указанного заказа, то:   
1. Система выводит на экран сообщение о доступном количестве бумаги и предлагает пользователю изменить параметры заказа или завершить сессию  
2. Если пользователь согласен изменить количество фото, то управление переходит на шаг 8  
3. Иначе переход в поток исключения 3б

**Альтернативный поток 14а**

Если попытка оплаты оказалась неудачной,то:

1. Терминал оповещает о неудачной попытке оплаты и предлагает повторить попытку  
2. Если пользователь согласен продолжить, то управление переходит на этап 13  
3. Иначе переход в поток исключения 3б
   
#### **3.6 Потоки исключений**

   Если пользователь хочет прервать заказ на любом этапе до оплаты:

1. Пользователь завершает сессию  
2. Система отображает главный экран  
3. Вариант использования завершает свою работу  
     
#### **3.7 Постусловия:**

1. Фотографии удачно распечатаны  
2. Система автоматически закрыла сессию для защиты данных.  
3. Автомат вернулся в режим ожидания следующего клиента.

 #### **3.8 Результат**

Если ВИ выполнен успешно, то фотографии распечатаны

### 4. **При разработке программного обеспечения для автомата печати фото необходимо учесть обработку следующих системных ошибок:**

#### **1. Ошибки подключения и работы с телефонами:**

1.1 Не удалось подключить телефон:  
Если телефон пользователя не распознан при подключении через кабель, автомат должен уведомить пользователя: «Телефон не подключён. Проверьте кабель или порт».  
1.2 Проблемы с доступом к файлам телефона:  
Если автомат не может получить доступ к фото, следует показать сообщение: «Нет доступа к фотографиям. Разрешите доступ на вашем устройстве».

#### **2. Ошибки взаимодействия с Instagram:**

2.1 Профиль пользователя недоступен.  
Если профиль закрыт или недоступен из\-за проблем с сетью, система должна вывести сообщение: «Не удалось подключиться к профилю Instagram. Проверьте настройки или интернет-соединение».  
2.2 Неверный логин:  
Если пользователь ввёл неверные данные для входа, система должна уведомить: «Логин указан неверно. Повторите попытку».

#### **3. Ошибки ресурсов автомата:**  

3.1 Недостаточно бумаги или чернил.  
Если в автомате недостаточно ресурсов для печати выбранного количества фотографий, система должна вывести сообщение: «Недостаточно ресурсов для печати. Уменьшите количество фотографий или обратитесь за помощью».  
3.2 Зависание механизма печати.  
Если печать фотографий прерывается из\-за сбоя, система должна уведомить пользователя: «Ошибка печати. Обратитесь за помощью».

#### **4. Ошибки оплаты:** 

4.1 Сбой терминала оплаты:  
Если терминал не работает или произошла ошибка при оплате, система должна отобразить: «Не удалось провести оплату. Попробуйте снова или используйте другую карту».  
4.2 Отклонение карты:  
Если карта пользователя отклонена, должно быть сообщение: «Оплата отклонена. Используйте другую карту или попробуйте снова».

#### **5. Ошибки программного обеспечения:** 

5.1 Сбой интерфейса.  
Если приложение зависло или внезапно завершило работу, автомат должен перезагрузить интерфейс и вернуть пользователя на главный экран.  
5.2 Непредвиденные ошибки.  
Для любых других ошибок, которые не были предусмотрены, система должна показывать общее сообщение: «Произошла ошибка. Попробуйте снова или обратитесь за помощью».

#### **6. Ошибки ввода данных:**

 Выбрано недопустимое количество фотографий:  
Если пользователь выбирает меньше 1 или больше 100 фотографий, система должна отобразить сообщение: «Выбранное количество фотографий недопустимо. Укажите значение от 1 до 100».

#### **7. Ошибки сети:**  
Отсутствие подключения к интернету:  
Если автомат потерял доступ к сети, система должна уведомить: «Нет подключения к интернету. Попробуйте снова позже».
