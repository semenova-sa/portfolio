## Кейс: Автоматизация бронирования в отеле
### Что сделала:

- Собрала и структурировала требования заказчика (клиент + система).

- Спроектировала процесс бронирования в нотации BPMN 2.0 (collaboration diagram).

- Разработала структуру пулов и дорожек: система («Витрина/Поиск», «Оплата/Биллинг», «Уведомления/Почта»), клиент, платёжный провайдер, служба размещения.

- Проработала ветвления через шлюзы (доступность номеров, выбор оплаты, скидка постоянным клиентам).

- Описала события отмены, ожиданий и внешних сигналов (таймер, сообщение).

- Сформулировала 3 предложения по оптимизации процесса (выручка, затраты, UX).

### Инструменты:
