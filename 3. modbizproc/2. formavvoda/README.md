## Кейс 2: Модель формы ввода информации о новом поставщике
### Краткое описание системы:
Проектирование модели данных и формы ввода для регистрации нового поставщика (юридического лица, зарегистрированного в РФ) в корпоративной системе. Задача включала описание перечня полей, типов данных, правил валидации, используемых справочников и способов хранения информации.
### Что сделала:
- Собрала требования к форме ввода: определен полный перечень полей (наименование, ИНН, КПП, ОГРН, адреса, банковские реквизиты, контактные данные).

- Спроектировала модель данных: описала типы данных для каждого поля (текстовый, логический), максимальную длину, обязательность заполнения.

- Разработала правила валидации: проверка числовых символов, длины номера, формата email, формата сайта, непустых значений.

- Определила источники данных: указала, какие поля заполняются вручную, а какие — автоматизированно через справочники (DaData, ЕГРЮЛ/ФНС, БИК-справочник, ФИАС).

- Описала способ хранения: определила, как каждое поле будет храниться в базе данных (тип, длина).

- Спроектировала интерфейс ввода: указала, как каждое поле будет выглядеть на экране (свободное поле ввода, переключатель, поле с маской).
